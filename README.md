# Student Task Manager

A modern and responsive task management web application built using HTML, CSS, and JavaScript.

## Features

* Add tasks
* Delete tasks
* Mark tasks as completed
* Local storage support
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
